# Документация к главе 8: Контроллеры внешней памяти

В данной папке содержится подробный анализ материалов 8-й главы, посвященной работе с IP-ядром Xilinx MIG и внешней памятью DDR2.

## Содержание

1.  **[ГЛАВА_8_АНАЛИЗ.md](./ГЛАВА_8_АНАЛИЗ.md)** — Основной документ анализа:
    *   Сравнение типов памяти (BRAM vs DRAM).
    *   Архитектура IP-ядра **MIG** и протокол **DDR2**.
    *   Процесс запуска и калибровки памяти.
    *   Разбор интерфейса **AXI4 Slave** в контроллере памяти.
    *   Анализ эталонного дизайна и симуляционных моделей.

2.  **[images/](./images/)** — Визуализации ключевых концепций:
    *   `chapter_8_memory_hierarchy.png` — Сравнение характеристик памяти.
    *   `chapter_8_mig_block_diagram.png` — Внутренняя структура контроллера.
    *   `chapter_8_init_calibration_timeline.png` — Диаграмма состояний при включении.
    *   `chapter_8_vga_framebuffer_concept.png` — Обоснование использования DDR для видео.
    *   `chapter_8_axi_burst_access.png` — Визуализация эффективности AXI шины.

## Ключевые проектные артефакты в репозитории

*   `CH8/build/ddr2/` — Базовый проект с сконфигурированным IP контроллером.
*   `CH8/build/ddr2_example/` — Сгенерированный Vivado пример (Example Design) для изучения.
*   `CH8/build/ddr2/ddr2.srcs/sources_1/ip/ddr2_controller/ddr2_controller_stub.v` — Основной "контракт" портов модуля.

# Документация к главе 7: Блочные дизайны и интеграция IP

В этой папке содержится подробный анализ материалов 7-й главы, посвященной переходу от монолитного HDL к проектированию систем на кристалле (SoC) с использованием Vivado Block Design и интерфейсов AXI.

## Содержание

1.  **[ГЛАВА_7_АНАЛИЗ.md](./ГЛАВА_7_АНАЛИЗ.md)** — Основной документ анализа:
    *   Концепция IP-ядер и их жизненный цикл в Vivado.
    *   Обзор семейства интерфейсов **AMBA AXI** (Full, Lite, Stream).
    *   Разбор архитектуры Block Design на примере проекта измерения температуры.
    *   Детальный анализ кода модулей (`adt7420_i2c`, `flt_temp`, `seven_segment`).
    *   Практический пример реализации **AXI4-Lite Slave**.
    *   Методы отладки через **System ILA**.

2.  **[images/](./images/)** — Визуализации ключевых концепций:
    *   `chapter_7_system_architecture.png` — Книжная архитектура системы.
    *   `chapter_7_bd_vs_hdl_flow.png` — Поток проектирования (Design Flow).
    *   `chapter_7_axi_family_overview.png` — Классификация интерфейсов AXI.
    *   `chapter_7_axi_lite_handshake_timing.png` — Тайминги рукопожатия AXI-Lite.
    *   `chapter_7_axis_valid_pipeline_timing.png` — Распространение `tvalid` по конвейеру.

## Ключевые проектные артефакты

*   `CH7/build/i2c_temp_flt_bd/` — Проект Vivado с блочным дизайном.
*   `CH7/build/IP/` — Репозиторий собственных упакованных IP-ядер.
*   `CH7/build/ip_repo/pdm_capture/` — Шаблонный проект AXI-Lite устройства.
*   `CH7/hdl/adt7420_i2c_mod.sv` — Ядро датчика, адаптированное под AXI Stream стиль.

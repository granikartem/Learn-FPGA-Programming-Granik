# Документация к главе 9: VGA, память и графика

В данной папке содержится подробный анализ материалов 9-й главы, посвященной созданию видеосистемы с использованием кадрового буфера в DDR2 и генерацией сигналов VGA.

## Содержание

1.  **[ГЛАВА_9_АНАЛИЗ.md](./ГЛАВА_9_АНАЛИЗ.md)** — Основной документ анализа:
    *   Принципы работы протокола VGA и временные интервалы (Porch, Sync).
    *   Архитектура видео-конвейера от DDR2 до пикселей.
    *   Реализация универсального контроллера с переключением режимов через свитчи.
    *   Разбор регистровой модели управления (AXI-Lite Style).
    *   Детальный анализ модулей `vga_core` и `text_rom`.

2.  **[images/](./images/)** — Визуализации ключевых концепций:
    *   `chapter_9_vga_horizontal_timing.png` — Горизонтальная развертка.
    *   `chapter_9_vga_vertical_timing.png` — Вертикальная развертка.
    *   `chapter_9_mode_select_sw_timing_table.png` — Логика выбора разрешения.
    *   `chapter_9_video_pipeline_overview.png` — Блок-схема системы.
    *   `chapter_9_text_rom_8x8_example.png` — Структура символов шрифта.

## Ключевые файлы анализа в главе 9

*   `CH9/hdl/vga_core.sv` — Основной модуль генерации видео и чтения памяти.
*   `CH9/hdl/text_rom.sv` — Генератор символов.
*   `CH9/hdl/vga.sv` — Топ-уровень интеграции.
*   `CH9/build/xdc/vga.xdc` — Ограничения для видео-выходов и органов управления.
